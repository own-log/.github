# OwnLog (온로그)

> **"나만의(Own) 기록(Log)"**: 기록이 시간과 연결로 자라는 블로그

누구나 가입해서 자기 블로그를 운영하는 **멀티유저 블로그 플랫폼**이에요 (티스토리형).
글이 목록으로 쌓이기만 하지 않고, **시간 축**(타임캡슐)과 **연결 축**(`[[글]]` 링크, 기록 우주)으로 이어져요.

🔗 **서비스: https://ownlog.java21.net**

## ✨ 기록 유니버스

| 기능 | 내용 |
|---|---|
| ⏳ 타임캡슐 | 정한 시각(1분 ~ 10년 뒤)에 열리는 글. 봉인 중에는 카운트다운만 보이고, 시간이 되면 새로고침 없이 열려요 |
| 💌 받는 사람 타임캡슐 | 다른 회원에게 보내는 캡슐. 열리면 받는 사람만 읽어요 |
| 🔗 `[[글]]` 연결 | 본문에서 다른 글을 연결하고, "이 글을 언급한 글"(백링크)과 링크 미리보기를 보여 줘요 |
| 🌌 기록 우주 | 글은 별, 링크와 내용이 비슷한 글은 선으로 이은 그래프. 타임랩스로 우주가 자라는 걸 볼 수 있어요 |
| 🌱 기록 잔디 | 1년 잔디와 🔥 연속 기록 |

그 밖에 회원가입·소셜 로그인(카카오·네이버·구글·깃허브), 마크다운 글쓰기와 이미지 업로드, 카테고리·태그·토픽, 댓글·좋아요·북마크·신고를 지원해요.

| DB | PostgreSQL 17 |
